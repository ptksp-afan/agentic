# ED-1070 (Bug, label ai-found) - V5 list - parameter search bukan JSON objek = 500; Archive - ubah folder bisa menjadikan folder induk dirinya sendiri

Deskripsi Jira (disalin epic loop 2026-10-08):

Ditemukan saat long run epic ED-1022 (item ED-1025, QA BE ronde 1 dan 2), di luar cakupan ED-1025. Semua perilaku sudah ada sebelum ED-1025 (identik di HEAD branch `v5-opname-archive`); tidak diperbaiki di ED-1025.

1. `search` list bukan JSON objek → 500 (umum v5, bukan hanya Archive): `GET api/v5/document-archive/archives?search=<nilai>` dengan nilai bukan JSON objek (`bukan-json`, `123`, `"str"`) → HTTP 500 `INVALID_DATA` / `Search request is invalid`; `search={"query":["a"]}` → 500 `Array to string conversion`. Harapan: 4xx (400/422). Penyebab: `CustomizeBuilder::scopeSearchAll` (`Modules/V5/Entities/Traits/CustomizeBuilder.php:96-97`) melempar `ErrorMessageException` tanpa kode HTTP (bawaan 500). Trait ini dipakai semua list v5, jadi kemungkinan semua list v5 berperilaku sama. Direproduksi QA (D-1).
2. **Ubah folder dengan induk = dirinya sendiri → 200, terbentuk siklus**: `PUT api/v5/document-archive/archives/{id}` dengan `id_archive_parent` = id folder itu sendiri diterima (200) dan folder menjadi induk dirinya. ED-1024 hanya melarang put-in ke diri sendiri (lihat juga ED-1069 butir 2 untuk put-in ke turunan). Perhitungan hak folder ED-1025 aman terhadap siklus, tetapi folder itu hilang dari pohon. Direproduksi QA (O-3).
3. **Parameter list generik salah bentuk → 500** (sekeluarga dengan butir 1, ditambahkan dari QA ronde 2, D-5): pada `GET api/v5/document-archive/archives`: `pagination=abc` (`A non-numeric value`), `pagination[]=1` (`Unsupported operand types`), `pagination=-1` (SQL syntax), `sorts=bukan-json` / `sorts={"name":"asc"}` (`INVALID_DATA` tanpa kode HTTP), `sorts[0]={"sortBy":"name"}` tanpa `sortType` dan `sorts[0]=["x"]` (`Illegal offset type`), `search[]=x` / `search[a]=b` (`json_decode() expects parameter 1 to be string`), `search={"showRelatedTransaction":["a"]}` (`Call to undefined method Archive::showRelatedTransaction()`). Penyebab: `$request->pagination` dipakai langsung (`ArchiveService.php:25`, `:86`), `CustomizeBuilder::scopeSortAll`/`scopeSearchAll` melempar `ErrorMessageException` tanpa kode HTTP, `json_decode` pada nilai array. Kemungkinan sama di list v5 lain.

**Usulan:** (1)+(3) beri kode 400 pada exception di `CustomizeBuilder` dan validasi `pagination`/`sorts`/`search` di satu tempat bersama — perubahan lintas module, perlu cek dampak; (2) tolak `id_archive_parent` = diri sendiri/turunan pada ubah folder (gabungkan dengan perbaikan ED-1069).

Rujukan: `agentic/features/ED-1025-archive-folder-permission/qa-be.md` § Dilacak di luar item (D-1, O-3, D-5); skenario `qa/scenario4-select-misc.php` X-8, `qa/scenario5-input-types.php` X-13.
